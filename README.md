# Collision Ring v3 — NO AUDIO LIMIT ☠️

- Starts with 2 balls
- Every new ball-to-ball collision spawns another ball
- All balls gradually shrink down to a hard minimum size
- Ball-to-ball collision physics
- Ring-wall bouncing
- Live stats
- 1x–10x simulation speed
- Collision clack + spawn pip
- High-population low thumps
- Wall-hit sounds
- UI sounds
- NO game-side audio rate limiting
- Every qualifying collision and wall impact can create audio
- Flat/root-only project
- No external assets

At very high ball counts and 10x speed, browser/device audio or performance limits may become the only remaining limit.
